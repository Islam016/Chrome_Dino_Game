# 🦖 Chrome Dino Game | لعبة الديناصور الكلاسيكية

لعبة ديناصور كروم الشهيرة بتصميم عصري نظيف (Clean Minimalist / Dark Mode)، مبنية باستخدام HTML5, CSS3, و Vanilla JavaScript.

[استعرض اللعبة أونلاين](#) · [الإبلاغ عن مشكلة](../../issues)

</div>

---

## 🌟 مميزات المشروع

- **تصميم عصري راقٍ:** واجهة مستخدم هادئة تدعم الوضع المظلم (Dark Mode) بلمسات عصرية.
- **تخزين النقاط (High Score):** يتم حفظ أعلى نتيجة حققتها تلقائياً في المتصفح باستخدام `LocalStorage`.
- **بدون مكتبات خارجية:** اللعبة مكتوبة بالكامل بلغات الويب الأساسية لضمان السرعة وسفة الأداء.
- **استجابة كاملة:** تعمل بسلاسة على أجهزة الكمبيوتر والأجهزة اللوحية (باستخدام زر المسافة أو النقر).

---

## 🛠️ التقنيات المستخدمة

- **HTML5:** لهيكل اللعبة وعناصر الواجهة.
- **CSS3:** للتنسيق والتصميم والحركات البصرية (Animations) مع تأثيرات Blur/Glassmorphism.
- **JavaScript (ES6):** للتحكم في المنطق، الجاذبية، القفز، فحص الاصطدام، والعدادات.

---

## 🚀 طريقة التشغيل محلياً (Local Setup)

إذا كنت ترغب في تشغيل المشروع على جهازك الشخصي:

1. قم بنسخ المستودع (Clone) أو تحميله كملف ZIP:
   ```bash
   git clone https://github.com/YOUR-USERNAME/chrome-dino-game.git
   ```
2. افتح المجلد باستخدام أي محرر أكواد (مثل Visual Studio Code).
3. افتح ملف `index.html` مباشرة في متصفح الويب لديك واستمتع باللعبة!

---

## 🎮 طريقة اللعب

1. اضغط على زر **"ابدأ اللعبة"** أو اضغط على مفتاح **المسافة (Space)** في لوحة المفاتيح.
2. اضغط على **المسافة** أو انقر بالماوس لجعل الديناصور يقفز فوق الصبار.
3. حاول تجنب الاصطدام بالصبار للحصول على أعلى نتيجة ممكنة!
