## 🌟 مميزات المشروع

- **التصميم الأصلي (Google Style):** واجهة مستخدم تحاكي اللعبة الأصلية بدقة مع دعم التبديل السلس بين الثيم الفاتح والداكن (عبر زر عائم في أسفل الصفحة).
- **تدرج السرعة التلقائي:** تتسارع اللعبة تدريجياً كلما تقدمت في إحراز النقاط لزيادة الحماس والتحدي.
- **تخزين النتائج (High Score):** حفظ أعلى نتيجة محققة تلقائياً عبر خاصية `LocalStorage` في المتصفح.
- **دعم كامل للأجهزة:** تجربة لعب سلسة وسريعة على الهواتف الذكية (باللمس) وأجهزة الكمبيوتر (بلوحة المفاتيح والماوس).
- **بدون تبعات خارجية:** مبنية بلغات الويب الأساسية بالكامل (Vanilla HTML5, CSS3, JavaScript) لضمان خفة وسرعة الأداء.

---

## 🛠️ التقنيات المستخدمة

- **HTML5:** الهيكل الأساسي للعبة وعناصر واجهة المستخدم.
- **CSS3:** تنسيق العناصر بأسلوب البيكسل (Pixel Art)، الأنيماشن، وإدارة المتغيرات (CSS Variables) للثيمات.
- **JavaScript (ES6):** إدارة منطق اللعبة، محاكي الجاذبية والقفز، خوارزمية فحص الاصطدام، وتدرج السرعة.
