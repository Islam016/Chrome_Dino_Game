## 🌟 المميزات

- **تصميم قريب من الأصلي** مع زر عائم للتبديل بين الثيم الفاتح والداكن، والاختيار بيتحفظ.
- **Game loop حقيقي** مبني على `requestAnimationFrame` مع delta time، فاللعبة بنفس السرعة على شاشات 60 و 120 هرتز.
- **فيزياء قفز** بالجاذبية والسرعة الابتدائية بدل أنيميشن CSS ثابت.
- **صعوبة متدرجة**: السرعة بتزيد كل 100 نقطة، والمسافة بين الصبّار عشوائية.
- **كشف اصطدام دقيق** بالـ bounding boxes مع هامش بسيط، فبيشتغل صح على أي عرض شاشة.
- **تحكم موحّد** بـ Pointer Events: ماوس أو لمس أو قلم من غير ما اللمسة تتحسب مرتين، والكيبورد بـ `Space` أو `↑` أو `Enter`.
- **أعلى نتيجة** محفوظة في `localStorage`، واللعبة شغالة حتى لو التخزين مقفول (Private mode).
- **بدون أي مكتبات خارجية**.

## 🎮 طريقة اللعب

| --- | --- |
| الكمبيوتر | `Space` أو `↑` أو `Enter` أو كليك على الملعب |
| الموبايل | المس الملعب |

## 🛠️ التقنيات

- **HTML5** لهيكل اللعبة.
- **CSS3** للثيمات بالـ CSS Variables وتنسيق البيكسل.
- **JavaScript (ES2020)** للـ game loop والفيزياء والاصطدام والتخزين.

## 🧠 إزاي اللعبة شغالة

```
requestAnimationFrame ─► update(dt) ─► draw() ─► collides()?
                           │                         │
                 score, speed, gravity        game over / continue
```

- `update(dt)` بيحرّك الديناصور والصبّار حسب الوقت اللي فات من آخر فريم، وبيزوّد السرعة كل 100 نقطة.
- `draw()` بيحرّك العناصر بـ `transform` عشان الأداء يبقى سلس.
- `collides()` بيقارن مستطيلات العنصرين بعد ما يصغّرهم شوية، عشان الاصطدام يبقى عادل.

## 🚀 التشغيل محليًا

```bash
git clone https://github.com/Islam016/Chrome_Dino_Game.git
cd Chrome_Dino_Game
```

افتح `index.html` في المتصفح، أو شغّل سيرفر بسيط:

```bash
npx serve .
```
