## 🌟 المميزات

**زي اللعبة الأصلية**
- ملعب 600×150 مرسوم على `<canvas>` بأسلوب البكسل، وكل الرسومات مكتوبة بالكود كـ pixel grids.
- الديناصور **بيجري** برجلين بيتبدّلوا، **بيقفز** بفيزياء جاذبية حقيقية، **بيوطّي** تحت الطيور، وعينه بترمش وهو مستني، وبتتحوّل لـ ✕ لما يخسر.
- قفزة متغيّرة: لو سبت الزرار بدري القفزة بتقصر، ولو ضغطت ↓ وهو في الهوا بينزل بسرعة.
- **صبّار صغير وكبير** بييجي فرادى أو مجموعات، و**طيور** بتظهر بعد سرعة معيّنة على 3 ارتفاعات وجناحها بيرفرف.
- السرعة بتزيد تدريجيًا من 6 لحد 13، والمسافة بين العوائق بتتغيّر حسب السرعة، ومفيش نفس العائق أكتر من مرتين ورا بعض.
- **أرض بتتحرك** فيها نتوءات وحصى، و**سحاب** بيتحرك أبطأ (parallax).
- **وضع ليلي** كل 700 نقطة: الألوان بتتعكس تدريجيًا ويظهر القمر والنجوم.
- **النتيجة** بخط بكسل، بترمش وبتطلع صوت كل 100 نقطة، وأعلى نتيجة (HI) بتتحفظ.
- شاشة **GAME OVER** وأيقونة إعادة اللعب.
- **أصوات** للقفز والإنجاز والاصطدام بـ Web Audio، ومعاها زرار كتم.

**تحسينات تقنية**
- **اصطدام بدقة البكسل**: المستطيلات بتتقارن الأول، وبعدين بيتم فحص البكسلات المتداخلة فعليًا، فمفيش خسارة ظالمة.
- Game loop بـ `requestAnimationFrame` محسوب على 60 فريم في الثانية، فاللعبة بنفس السرعة على شاشات 60 و 120 هرتز.
- رسم حاد على شاشات Retina، بنسبة تكبير صحيحة عشان ميظهرش خطوط بين البكسلات.
- اللعبة بتقف لوحدها لما تبدّل التاب.
- وضع داكن يدوي، والإعدادات بتتحفظ، واللعبة شغالة حتى لو التخزين مقفول.

## 🎮 التحكم

| الجهاز | قفز / بدء | توطية |
| --- | --- | --- |
| الكمبيوتر | `Space` أو `↑` أو `Enter` أو كليك | `↓` (وفي الهوا: نزول سريع) |
| الموبايل | المس الملعب | المس الربع السفلي من الملعب |

## 🧠 إزاي اللعبة معمولة

```
requestAnimationFrame
        │
        ▼
  update(frames)  ── سرعة · مسافة · فيزياء الديناصور · عوائق · سحاب · ليل/نهار
        │
        ├── collides()  ── AABB ثم pixel-perfect
        │
        ▼
     draw()       ── خلفية · قمر/نجوم · سحاب · أرض · عوائق · ديناصور · نتيجة
```

| الملف | المحتوى |
| --- | --- |
| `sprites.js` | كل الرسومات (ديناصور، صبّار، طيور، سحاب، قمر) وخط الأرقام 5×7 |
| `script.js` | منطق اللعبة: الحالة، الفيزياء، العوائق، الاصطدام، الرسم، التحكم، الأصوات |
| `style.css` | التنسيق والثيمات |
| `index.html` | الصفحة |

## 🚀 التشغيل محليًا

```bash
git clone https://github.com/Islam016/Chrome_Dino_Game.git
cd Chrome_Dino_Game
npx serve .
```

أو افتح `index.html` في المتصفح على طول.
